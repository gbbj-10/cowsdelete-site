Claude 로 연결하기

무카 CAD 는 AI 를 직접 부르지 않습니다. 내 PC 에 설치하는 연결 프로그램이 내 Claude(Claude 앱)와 무카 CAD 화면을 이어 주고, 사용량은 내 Claude 구독에서 나갑니다. 준비물: Windows·Mac 용 Claude 데스크톱 앱(claude.ai/download)과 로그인.

1연결 파일 받기

무카 CAD 오른쪽 위 [Claude 연결](테스트 서버는 [AI 연결]) 버튼을 누릅니다.

열린 창에서 노란 [Claude 연결 파일 받기]를 누르면 mucca-cad.mcpb 파일이 다운로드 폴더에 받아집니다.

⚠ 파일을 받은 무카 CAD 창은 닫지 말고 그대로 두세요. 이 창이 설치가 끝나기를 기다렸다가 자동으로 연결합니다.

2Claude 앱에 설치 — 둘 중 편한 방법 하나

방법 A · 받은 파일을 더블클릭 (가장 쉬움)

다운로드 폴더에서 mucca-cad.mcpb 를 더블클릭하면 Claude 앱이 열리면서 설치 창이 뜹니다. [설치]를 누르면 끝입니다.

방법 B · Claude 앱 설정에서 설치 (더블클릭이 안 될 때)

  2. 왼쪽 목록에서 확장 프로그램을 고릅니다. 새 버전은 데스크톱 앱 › 확장 프로그램 옆 [관리] 입니다.

설치하면 확장 프로그램 목록에 무카 CAD가 보입니다. 꺼져 있으면 켜 주세요. 메뉴가 안 보이면 Claude 앱을 최신으로 업데이트한 뒤 다시 해 보세요.

3자동 연결 확인

설치가 끝나면 (닫지 않고 둔) 무카 CAD 화면이 저절로 연결되고, 창 위쪽 불이 초록색으로 바뀝니다.

그다음 Claude 앱 대화에서 "무카 CAD에 플랜지 그려줘"처럼 말하면 무카 CAD 화면에 그려집니다.

Claude 가 잘 안 될 때

  • 몇 분이 지나도 회색 불 — Claude 앱을 완전히 껐다 켭니다(Windows 작업 표시줄 오른쪽 아래 아이콘에서도 종료). 그래도 안 되면 무카 CAD 연결 창의 「자동 연결이 안 될 때」를 펼쳐 Claude 앱에 "무카 연결 코드 알려줘"라고 물어 나온 6자리를 넣으세요.
  • 다른 PC·다른 브라우저로 바꾸면 그 PC 에서 1~2번을 한 번 더 합니다.
  • "예전 버전" 안내가 나오면 [새 연결 파일 받기]로 받은 파일을 2번처럼 다시 설치합니다.

Gemini 로 연결하기

Gemini 는 내 PC 의 Gemini CLI(구글이 만든 명령 창용 Gemini)로 그립니다. 무카 CAD 가 준 연결 프로그램(mucca-mcp.js)이 Gemini CLI 와 무카 CAD 화면을 이어 줍니다. 처음 한 번만 아래 1~4번을 하면, 다음부터는 4번 명령 한 줄만 다시 실행하면 됩니다.

먼저 확인하세요 — Gemini 유료 구독(Google AI Pro·Ultra)만으로는 안 됩니다.
구글이 2026년 6월 18일부터 개인 구글 계정(무료·Google AI Pro·Ultra) 로그인으로는 Gemini CLI 를 쓸 수 없게 바꿨습니다(무카 CAD 문제가 아니라 구글 정책). 그래서 Gemini 로 그리려면 유료 Gemini API 키(구글 AI Studio 에서 결제를 연결한 키)가 필요하고, 요금은 그 키의 구글 결제에서 따로 나갑니다.
구독만 있고 API 키를 따로 만들기 싫다면 GPT(ChatGPT 계정)나 Claude 로 연결하는 편이 쉽습니다.

명령은 Windows 는 명령 프롬프트(cmd) — 시작 메뉴에서 "cmd" 검색 — , Mac 은 터미널에 붙여 넣고 Enter 를 누르세요. 아래 검은 창 그림은 이해를 돕는 예시입니다.

1Node.js 설치 (처음 한 번)

nodejs.org 에서 LTS 버전을 받아 설치합니다(설치 창은 [다음]만 눌러도 됩니다). 설치가 끝나면 명령 창을 새로 열고 아래처럼 확인합니다.

명령 프롬프트
C:\Users\내이름> node -v
v22.12.0   ← 숫자가 나오면 성공 (20 이상이면 됩니다)

"'node'은(는) 내부 또는 외부 명령… 이 아닙니다" 가 나오면 명령 창을 닫고 새로 열어 다시 해 보세요. 그래도 같으면 Node.js 를 다시 설치합니다.

2Gemini CLI 설치 (처음 한 번)

명령 프롬프트
C:\Users\내이름> npm i -g @google/gemini-cli
…
added 4xx packages in 40s   ← 이런 줄이 나오면 끝

Mac 에서 권한 오류가 나면 앞에 sudo 를 붙입니다. Windows PowerShell 에서 "스크립트를 실행할 수 없으므로" 오류가 나면 명령 프롬프트(cmd)에서 다시 실행하세요.

3Gemini API 키 등록 (처음 한 번)

  1. 구글 AI Studio › API 키 에서 키를 만들고 결제(Billing)를 연결합니다. 키는 AIza… 로 시작하는 긴 글자입니다. 남에게 보여 주지 마세요.
  2. 명령 창에서 gemini 를 실행하면 로그인 방법을 묻습니다. Use Gemini API Key 를 고르고 키를 붙여 넣습니다.
  3. 입력창이 뜨면 /quit 를 쳐서 닫습니다.
명령 프롬프트 · gemini
C:\Users\내이름> gemini
Get started — How would you like to authenticate for this project?
  ○ Login with Google           ← 개인 계정·구독 로그인: 지금은 안 됨
  ● Use Gemini API Key           ← 이것을 고르고 키 붙여 넣기
  ○ Vertex AI
…
> /quit

다른 방법: 내 사용자 폴더의 .gemini 폴더에 .env 파일을 만들고 GEMINI_API_KEY=내 키 한 줄을 넣어도 됩니다. 실제 문구·순서는 Gemini CLI 버전에 따라 조금 다를 수 있습니다.

4연결 프로그램 받아서 켜기

무카 CAD 오른쪽 위 [AI 연결] → 어떤 AI를 쓰세요? 에서 Gemini 를 누릅니다.

창 아래 ③ 의 노란 [연결 프로그램 받기 (mucca-mcp.js)] 를 누르면 다운로드 폴더에 파일이 받아집니다. 그다음 명령 창에 ③ 의 명령을 붙여 넣습니다.

명령 프롬프트 · 이 창은 닫지 마세요
C:\Users\내이름> cd %USERPROFILE%\Downloads && node mucca-mcp.js

──────────────────────────────────────────────
  무카 CAD 연결 프로그램 v1.0.7
──────────────────────────────────────────────
  연결 코드 :  123456
  → 무카 CAD 상단 [Claude 연결] 창에 이 코드를 넣으세요.
  Claude Code : 없음 — AI 입력칸을 쓰려면 설치·로그인 필요   ← Gemini 만 쓰면 괜찮습니다
  이 창을 닫으면 연결이 끊깁니다.
──────────────────────────────────────────────
[mucca] 무카 CAD 화면 연결됨

이 검은 창이 열려 있는 동안만 연결됩니다. 다음에 쓸 때도 이 명령 한 줄만 다시 실행하세요. 파일 이름이 mucca-mcp (1).js 처럼 바뀌었으면 명령의 이름도 똑같이 바꿉니다.

5Gemini 고르고 그리기

무카 CAD 화면 위 [AI 연결] 불이 초록으로 바뀌면 연결된 것입니다. 오른쪽 AI로 그리기 칸 아래 목록에서 Gemini 를 고르고, 요청(예: "바깥지름 120 플랜지 그려줘")을 쓴 뒤 [그리기] 를 누릅니다.

그림은 예시 화면입니다. Gemini CLI 를 방금 설치했다면 무카 CAD 를 한 번 새로고침하세요.

Gemini 가 잘 안 될 때

  • "무카 CAD 도구(mucca_*)가 연결되어 있지 않다"고 답함 — 최신 Gemini CLI(0.41 이후)에서 생기던 문제로, 연결 프로그램 v1.0.7 에서 고쳤습니다. [AI 연결] 창에서 연결 프로그램을 새로 받아 4번 명령을 다시 실행하세요(검은 창 맨 위 버전이 v1.0.7 이상인지 확인).
  • "Antigravity 로 옮기라" / IneligibleTier / 410 안내 — 개인 구글 계정 로그인이 막힌 것입니다. 3번처럼 API 키로 다시 등록하세요(gemini 실행 후 /auth).
  • Gemini 가 목록에 없음 — 연결 창에서 Gemini [다시 찾기]를 누르거나 무카 CAD 를 새로고침합니다. 그래도 없으면 2번 설치를 다시 확인하세요.
  • 회색 불 — 4번 검은 창이 닫혔거나 다른 폴더에서 실행한 경우입니다. 다운로드 폴더에서 4번 명령을 다시 실행하세요.

그래도 막히면 문의 게시판에 화면 캡처와 함께 남겨 주세요.
