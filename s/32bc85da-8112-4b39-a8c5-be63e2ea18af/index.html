M10 육각볼트+너트 체결 (KS B 1002·1012)

흑우2026.11.05 02:05가져감 0좋아요 0
M10 육각볼트 + 평와셔 + 육각너트 체결 상태. 왼쪽 = 체결 정면도(판은 단면), 오른쪽 = 너트 쪽에서 본 모양. 볼트 ISO 4017 / KS B 1002 M10×40(피치 1.5, 맞변 16, 머리 높이 6.4) · 너트 ISO 4032 / KS B 1012 M10(맞변 16, 높이 8.4) · 평와셔 ISO 7089 M10(바깥 20, 안 10.5, 두께 2) · 볼트 구멍 Ø11(ISO 273 보통급). 판 두께 12+12 는 예시입니다. 기준점 = 볼트 축 중심 · 머리 아랫면(체결면). 길이는 늘이기(S)로 바꿔 쓰세요. 치수는 공개 규격표 값입니다. 제작 도면에 쓰기 전에 사용하는 규격판과 한 번 더 대조해 주세요. #볼트 #너트 #볼트너트 #체결 #M10 #와셔 #KS #ISO
