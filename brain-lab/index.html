무카의 두뇌

엔지니어의 현장 지식과 AI 작업 지침을 카드로 쌓고, 필요한 카드만 꺼내 씁니다. 사람은 지식 카드를 읽고, AI(Claude Code)는 지침 카드를 그 일을 할 때만 펼칩니다.

AI 가 가져가는 모양 (이 카드 1장)


        

      

    


    

      

        
내 클로드 코드에 설치 (지침 카드)

        
claude plugin marketplace add gbbj-10/mucca-brain

        
claude plugin install brain@mucca-brain

        
claude plugin install design-team@mucca-brain

        
claude plugin install creator@mucca-brain

        
brain = 공통 지침 · design-team = 기계설계 에이전트 팀 · creator = 영상·글 올리는 사람용. 테스트 기간에는 저장소가 비공개라 운영자 계정에서만 받을 수 있습니다.

      

      

        
왜 카드인가

        
지침을 통째로 넣으면 매 세션 그만큼 읽습니다. 카드로 나누면 평소엔 카드 이름과 한 줄 설명만 읽고, 그 일을 할 때 카드 한 장만 펼칩니다.

        

        
토큰 수는 Claude Code 가 보여 주는 추정값입니다. 실제 절감은 시험으로 확인 중입니다 [가설].

        
카드 제안하기 제안 → 검토 → 반영 순서로만 바뀝니다.
